## План: Hero-секция для лендинга вайбкодинг-специалиста

Создаю Hero-секцию по референсу: тёмная схема + неоновые акценты (фиолетовый, розовый, оранжевый градиент).

### Что меняю

- `**src/styles.css**` — добавляю тёмные токены и неоновые акцентные переменные (`--neon-purple`, `--neon-pink`, `--neon-orange`, градиенты, свечения). Применяю dark по умолчанию на body.
- `**src/components/Hero.tsx**` (новый) — секция с двухколоночной композицией:
  - Левая часть: badge-чип "ВАЙБКОДИНГ × AI × ПРОДУКТЫ", H1 "Создаю AI-продукты через вайбкодинг" (вторая строка с градиентным текстом фиолетовый→розовый→оранжевый), подзаголовок, две CTA-кнопки (оранжевая с градиентом + свечением "Посмотреть проекты", фиолетовая outlined с glow "Связаться"), блок статов (30+, 12+, 95%, 4.9/5).
  - Правая часть: мок-дашборд "NeiroPanel" — сайдбар с пунктами меню, карточки метрик (Пользователи / Выручка / Конверсия), SVG-график «Динамика» с градиентной заливкой, мини-карточки Build/Код и AI-ассистент.
- `**src/routes/index.tsx**` — заменяю placeholder на `<Hero />` (остальное не трогаю).

### Технические детали

- Стек: TanStack Start + Tailwind v4 + semantic tokens (никаких hardcoded цветов в компонентах).
- Шрифты: системные sans-serif с tight tracking для заголовка (можно подключить Inter через link, но обойдусь дефолтом стека для скорости).
- График: inline SVG с linearGradient (fuchsia→purple) + tooltip «17 мая 12,540».
- Адаптив: на мобильном grid → single column, дашборд скрывается ниже `lg` или показывается уменьшённый; шрифт H1 clamp(2.25rem, 6vw, 4.5rem); кнопки full-width на мобильном; статы в 2×2 сетке.
- Без новых зависимостей. Иконки — inline SVG (чтобы не тащить lucide ради 6 штук) либо переиспользую `lucide-react` если уже установлен.
